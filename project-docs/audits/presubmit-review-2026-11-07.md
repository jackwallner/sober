# Sober 1.3.8 pre-submit review (deep pass)

Live version 1.3.7, last commit before the 1.3.8 bump `bc629ef`. Reviewed the 1.3.7 to `origin/main` (`eb520f6`) app diff (Home week receipt, accessibility mood rows, Settings Language row, Reduce Motion in craving mode, DEBUG screenshot arguments, ro/tr localizations), then every user-reachable path on `origin/main`: purchase, restore, trial lifecycle, onboarding, SwiftData models and migration, check-ins and slips, notifications, widgets and Watch snapshot, iPhone Duo pane, localization. No simulator or local xcodebuild was used.

The 1.3.7 to 1.3.8 diff itself has no P0 or P1: the new launch arguments are all inside `#if DEBUG`, no `@Model` changed since 1.3.7, and the string catalog checks clean (778 keys, 23 languages, 0 problems). The P1 rows below are older bugs that ship in 1.3.7 too, several first reported in `state-machines-2026-11-06-review.md` (IDs in brackets) and still open on main.
